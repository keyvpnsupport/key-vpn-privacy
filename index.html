Политика конфиденциальности Key VPN

Дата вступления в силу: 9 сентября 2026 г.

Key VPN — расширение для Google Chrome, предназначенное для направления интернет-трафика браузера через приватный HTTPS-прокси.

Какие данные обрабатывает расширение

Данные для аутентификации. Пользователь вводит логин и пароль, необходимые для подключения к приватному прокси-серверу. Эти данные сохраняются локально в хранилище расширения Google Chrome и используются только для аутентификации на прокси-сервере.

Состояние подключения. Расширение локально сохраняет информацию о том, включено или выключено прокси-подключение.

Сетевой трафик. При включённом Key VPN трафик браузера Chrome проходит через приватный HTTPS-прокси. Прокси-сервер технически обрабатывает сетевые запросы, необходимые для предоставления функции подключения.

Key VPN не предназначен для сбора истории посещений, содержимого веб-страниц, поисковых запросов или действий пользователя в целях аналитики, рекламы или профилирования.

Как используются данные

  • для аутентификации пользователя на приватном прокси-сервере;
  • для включения и отключения прокси-подключения;
  • для маршрутизации трафика браузера через прокси;
  • для обеспечения основной функциональности расширения.

Хранение данных

Логин, пароль и состояние подключения сохраняются локально средствами Google Chrome.

Key VPN не использует собственную систему аналитики и не создаёт пользовательские профили.

Передача данных

Пользовательские данные не продаются третьим лицам.

Пользовательские данные не передаются третьим лицам для рекламы, маркетинга, определения платёжеспособности или иных целей, не связанных с основной функциональностью Key VPN.

Сетевой трафик передаётся только в объёме, необходимом для работы приватного прокси-сервера и дальнейшей маршрутизации интернет-соединения.

Защита данных

Соединение между расширением и прокси-сервером защищено с использованием HTTPS/TLS.

Данные для аутентификации передаются прокси-серверу только для установления разрешённого пользователю соединения.

Удаление данных

Пользователь может удалить сохранённые данные аутентификации через функцию смены пользователя в расширении либо удалить расширение из Google Chrome.

После удаления расширения локально сохранённые им данные удаляются средствами браузера Chrome.

Ограниченное использование данных

Использование информации, получаемой Key VPN через разрешения Chrome, ограничивается исключительно предоставлением и улучшением основной пользовательской функции расширения.

Key VPN не использует и не передаёт пользовательские данные для персонализированной рекламы, рекламного таргетинга, продажи данных или других целей, не связанных с работой расширения.

Изменения политики

Политика конфиденциальности может обновляться при изменении функциональности Key VPN или требований Chrome Web Store.
